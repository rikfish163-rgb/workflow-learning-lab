# 实验结果

结果按各次登记及独立终态审计记录。

## 工具纠错与经验复用

| 阶段 | 已核验事实 | 解释范围 |
| --- | --- | --- |
| [受控工具纠错](../evidence/state-recovery-fixture-001.json) | 4 个工作流均通过前读、明确未执行的拒绝、同参纠正和后读核验；68 次模型生成、64 次 API 调用 | 受控工作流上的局部状态目标 |
| 布尔证据提取 | 一次模型生成后主动弃权 | 单次观察 |
| [顺序证据提取](../evidence/state-recovery-writer-002.json) | 一次生成得到候选，通过结构筛查及一次模型复审，原文冻结 | 候选具备进入效用评测的资格 |
| 历史 train 配对评测 | 17/27 对完整、34 份官方评分，整组效应不可评 | 保留中断分支的未知状态 |
| 自编配对评测 | 27 对、54 份评分及 14 次 GPU 释放均经审计，两臂各通过 3/27，改善与受损对数均为 0 | 固定的 9 场景自编工作流面板 |
| 历史官方面板 002 | 12/27 对完整，25 个已知评分、1 个未知及 28 个未启动分支，7 次 GPU 释放已核验 | 第 26 个分支生成失败后退出，整组效应不可评 |
| [独立官方面板 003](../evidence/state-recovery-official-003.json) | 9 个未使用场景、27 对完整，54 份官方评分、14 次 GPU 释放核验，两臂均为 0/27 | 与旧面板场景重叠为 0，两臂共同增加 75 秒单次生成限制，正收益门槛未通过 |

自编面板的配对差值全部为 0，场景重采样区间退化为 `[0, 0]`，预登记的正收益门槛未通过。这组观测不足以建立更广泛的等效性。无经验臂有 22 次达到请求窗口限制，5 次自报完成；经验臂 27 次均自报完成，其中 24 次未通过终态评分。模型生成次数分别为 932 和 120。这些终止行为与成本数字属于事后描述性诊断。 [自编终态审计](../evidence/state-recovery-authored-003.json)

官方中断分支有 19 次生成意图、18 次返回，最后记录 `generation_failure`，未保存快照，也未启动评分。原终态保留未知和未启动分支，效应统计为空。终态及中断审计核验执行进程退出和 GPU 释放，底层生成失败原因仍未确定。 [官方终态审计](../evidence/state-recovery-official-002.json) · [中断审计](../evidence/state-recovery-official-interruption-002.json)

官方 003 的 27 对差值均为 0，场景重采样区间退化为 `[0, 0]`，不能据此证明总体等效。全失败使这组面板难以区分方法优劣。模型自报完成分别为 10/27 和 18/27，两臂均未获得官方成功。该终止行为差异属于事后诊断，不支持可靠性提升。

官方 003 共 1,075 次生成、946 次 API 调用、3,855,469 个提示 token、67,706 个输出 token，租用约 6.34 GPU 小时。这些数字仅覆盖该轮。27 对初始元数据匹配、54 个保存数据库及全部租约均经核验，物理设备为 GPU 8，各次空闲观察达到 180 秒。评测中 writer 和训练调用均为 0，经验原文保持冻结。 [完成核验与成本](../evidence/state-recovery-official-completion-003.json)

## 较早实验

| 实验 | 已核验事实 | 解释范围 |
| --- | --- | --- |
| B3 成功轨迹 SFT | 344 条动作样本，86 次更新，11,085 个监督 token，训练完成并导出 adapter | 训练完成与任务收益分别验证 |
| 自然 CodeAct 来源 | 固定 12 项任务全部认证，8 项官方通过，9 项自报完成 | 已暴露训练场景的小样本来源评测 |
| 自然来源恢复资格 | 1 个场景、10 个唯一动作目标 | 未达到该次登记的 4 场景、20 目标门槛 |
| 定向漏写恢复 | 两个受控场景中，模型补写恰好遗漏的目标，修复动作与返回经过核对 | 人为构造遗漏后的恢复行为 |

| 同输入 B0 诊断 | 一次生成，445 输入和 40 输出 token，模型弃权；实际消息与 B3 条件相同 | 单输入、单随机种子的探索性模型角色诊断 |
| 早期跨任务经验效用实现 | 该阶段真实执行 0/54 分支 | 当时尚无经验迁移效果估计 |

受控单次工具故障来源试验在桌面关机时中断，保留不完整结果。提取器的两次早期启动故障分别涉及部署依赖缺失和后端字段绑定，均在生成前退出，相关代码随后修复。正常预算停止、实验弃权和基础设施中断采用不同状态记录。

历史训练与模型运行使用原服务器上的登记文件、完整事件记录、内容哈希和资源释放凭据进行复核。此仓库提供汇总与实现，受保护输入及私有回执正文未上传。这里的摘要便于阅读，完整实验重现仍依赖这些外部资产。

当前尚无足以支持跨任务正收益、未见场景泛化或递归自我改进的实验结论。

本次交付完成了真实纠错、模型提取与独立跨任务验证的闭环，结果为未通过经验效用门槛。研究协议中的完整基线矩阵、经验内化后的无提示评测及多轮自我改进仍属后续研究，未记为已完成。当前候选没有触发新的参数更新，既有 SFT 只作为独立的训练工程记录。
